Type: task
Status: resolved
Triage: ready-for-agent

Marek requested “do big batch” on November 6 after the completed 20x/2fac
pilot. Scope: select twenty existing, unchanged, whole-template AppImage recipes
from the pinned recognition inventory; verify provenance, upstream identity,
selector policy and static payload desktop/icon compatibility; convert locally
only those passing all gates and regenerate declarations. Record exclusions
explicitly rather than relaxing gates to meet the target. Local source work is
authorized. Collection enrollment, pushes, publication, installed changes and
live deployment remain separate. No application payload is executed.

Use primary Git objects and first-party release API facts. Preserve compact
hash-checked evidence and exact source/asset identities. Prefer direct AppImage
assets and narrow observed-name patterns; preserve original desktop argument
stripping explicitly. Assess runtime differences against the completed pilot
and shared contract, including inert lifecycle checks. Existing custom/fork
recipes, missing upstreams and ambiguous payloads are excluded from conversion.

## Answer

[Batch report](../research/large-batch-conversion.md) and
[portable receipt](../research/large-batch-evidence.json) record **twenty source
conversions**. Thirty-one unchanged existing recipes were screened; 29 reached
payload preparation, 20 passed all gates and nine remain unchanged. Missing
published digests, absolute build-host icon links, distinct additional desktop
entries and missing desktop/Exec output remain explicit refusals. Two additional
metadata-stage exclusions concern payload size and repository identity redirect.

All twenty reconstruct byte-for-byte from original pinned Git templates; numeric
repository identities are verified against saved first-party APIs. Full payload
sizes/digests, complete listings and static desktop/icon link chains are retained
in compact hash-bound evidence. All old/new selected URLs agree on complete
saved first-page responses. Anchored numeric-version patterns, any-channel
publication ordering, retained-release selection, URL identity, normal freshness
and direct acquisition follow the pilot contract. Explicit desktop sandbox-flag
stripping preserves observed original transformations. No shared runtime change.

Validation: **43 focused tests pass**: 38 reconstruction/runtime/batch tests,
three declaration tests and two compiler tests. The three batch methods cover
20 exact reconstructions and primary identity/digest receipts, 60 comparisons
across mawk/gawk/BusyBox awk, and 20 actual-recipe inert install/update/removal
runs, with real static desktop/icon shapes and custom desktop/data preservation.
All 362 evidence manifest entries and archive SHA-256 verify. All nine excluded
source hashes remain unchanged; whitespace checks and repeatable generation pass.
No downloaded application code runs; no GUI or full catalog/container suite is
claimed. Locally acquired 3,738,516,565 bytes remain below the 4 GiB batch cap.

Declarations now total 43; collection enrollment remains **23 recipes / 21
repositories**. These twenty source conversions need separate collection
preparation/capacity checks and publication before production use. No push,
workflow/dispatch/publication, app install, live recipe/runtime refresh or yadm
pointer change occurred. Existing-install transition and historical launcher/
remover ownership remain separate from source conversion.
