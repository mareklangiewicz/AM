Keyboard shortcuts
All three layouts support the same keys. Tab, Shift-Tab, Enter and Space also work normally.
  • j / k Next / previous item in the current pane
  • h Focus app list · l Focus release details
  • Enter Open link or activate control · Space Toggle release / press button
  • gg / G First / last item in the current pane
  • Ctrl-d / Ctrl-u Scroll half a page (or app-list pane)
  • / Search · Esc Leave input / reset to all items
  • [ / ] or ← / → Previous / next layout
  • ? Show this guide · Esc Close it
Typing fields keep normal editing keys. External links and asset downloads require activation; moving focus never opens them.
