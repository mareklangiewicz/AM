# Triage labels

These values are local ticket metadata, not remote GitHub labels.

| Role | Value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Needs more information |
| ready-for-agent | ready-for-agent | Specified and ready for agent work |
| ready-for-human | ready-for-human | Requires human action |
| wontfix | wontfix | Will not be actioned |

Record the value on a Triage line, separately from execution Status.
