# AM catalog language

## Language

**Catalog**:
Published release facts offered to clients, without choosing which release a client should use.

**Client selection**:
A client's choice of release and assets for installation, browsing, presentation, or another purpose.

**Release window**:
The bounded set of published releases offered for a source in a catalog observation; it does not necessarily include the source's entire release history.

**Latest designation**:
The release GitHub identifies as latest for a source, distinct from a client's choice of release.

**Source check time**:
The time a source's catalog observation was last successfully validated against upstream.

**Publication time**:
The time a catalog snapshot was published, distinct from the check times of its sources.
